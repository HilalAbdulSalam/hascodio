# Hascodio website

Responsive static website for Hascodio, focused on practical automation and custom technology.

## Files
- `index.html`: company profile, services, process, contact form, and social links.
- `styles.css`: responsive layout, mobile navigation styles, and reduced-motion support.
- `script.js`: mobile navigation, service selection, and EmailJS enquiries.
- `assets/wordmark.svg`: existing Hascodio brand artwork.

Serve this directory with any static web server. Keep `CNAME` when deploying to the existing custom domain.
